# Comandos npm

## Desarrollo

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Calidad

```bash
npm run lint
npm run lint:fix
npm run format
```

## Prisma y base de datos

```bash
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
npm run prisma:seed:minimal
npm run prisma:studio
npm run db:status
npm run db:deploy
npm run db:verify
```

## Utilidades

```bash
npm run test:smtp
npm run reset:admin:local
```

## Otros

```bash
npm run generate
npm run nuxt:prepare
```
